# Guide d'administration — Royal Guest Garden

Ce guide s'adresse à l'équipe de l'hôtel. **Aucune compétence technique
n'est requise** : tout se fait depuis un navigateur, comme sur un site
d'e-commerce ou de banque en ligne.

---

## 1. Ouvrir le back-office

1. Ouvrez l'adresse **https://www.royalguestgarden.cm/admin**
   (ajoutez-la à vos favoris).
2. Saisissez votre **adresse e-mail** et votre **mot de passe**.
3. Cliquez sur « Se connecter ».

Mot de passe oublié ? Cliquez sur « Mot de passe oublié ? » : un e-mail
vous envoie un lien pour en choisir un nouveau (valable 1 heure).
Pensez à regarder dans les courriers indésirables (spam).

---

## 2. Première connexion (à faire une seule fois)

### Changer votre mot de passe

1. Menu **Mon compte** (en haut à droite).
2. Choisissez un mot de passe de **12 caractères minimum**, avec
   majuscules, minuscules et chiffres.
3. Cliquez sur « Enregistrer ».

### Activer la double authentification (fortement recommandé)

La double authentification (2FA) protège le back-office même si votre
mot de passe est volé.

1. Menu **Mon compte** → section « Double authentification ».
2. Installez une application de codes sur votre téléphone
   (Google Authenticator, Microsoft Authenticator ou équivalent).
3. Scannez le code QR affiché, saisissez le code à 6 chiffres, validez.
4. **Imprimez ou notez les codes de secours** et rangez-les en lieu sûr :
   ils permettent de vous connecter si vous perdez votre téléphone.

⚠ À partir de ce moment, la connexion demande votre mot de passe **et**
un code à 6 chiffres fraîchement généré par l'application.

---

## 3. Modifier un service (exemple complet)

Le site affiche 6 services : hébergement, restaurant, bar, piscine,
événements, tennis. Pour modifier l'un d'eux :

1. Menu **Contenu** → **Services**.
2. Cliquez sur le service à modifier (par exemple « Restaurant »).
3. Modifiez les champs. Chaque texte existe en deux versions,
   affichées **côte à côte** : français (obligatoire) et anglais.
   - **Titre** — nom du service.
   - **Résumé** — phrase affichée sur la page des services.
   - **Points forts** — liste des détails (ajouter, réordonner, retirer).
   - **Horaires** — ligne affichée dans le tableau des horaires.
   - **Tarifs** — « inclus », « en partie inclus » ou « en supplément »,
     avec des lignes tarifaires (libellé + prix en FCFA).
   - **Bouton WhatsApp** — « Demander des informations » ou
     « Demander un devis ».
   - **Icône** et **Photo** — visuel de la carte.
4. Cliquez sur « Enregistrer ».
5. Cliquez sur « Voir sur le site » pour vérifier le rendu.

**Publier / masquer** : la case « Publié » contrôle la visibilité sur le
site. Décochez-la pour préparer un changement sans le montrer au public,
puis recochez-la au moment voulu.

**Quand le changement apparaît-il ?** Sous **1 heure** pour les visiteurs
habituels, immédiatement pour les nouveaux visiteurs. Pour vérifier tout
de suite, ouvrez le site dans une fenêtre de navigation privée.

## 4. Autres contenus

Le même principe s'applique à toutes les rubriques du menu **Contenu** :

| Rubrique | Contenu |
|---|---|
| Chambres | Les 12 chambres : prix, capacité, lits, photos, équipements |
| Catégories | Familles de chambres (Standard, Supérieure…) |
| Équipements | Éléments cochables des chambres (Wi-Fi, clim…) |
| Services | Les 6 services (voir ci-dessus) |
| Avantages | Arguments de la page d'accueil |
| Témoignages | Avis des clients |
| Valeurs, Expériences | Sections de la page « À propos » |
| Équipe | Membres de l'équipe affichés sur le site |
| Galerie | Photos de la galerie |

- L'**ordre d'affichage** se règle par le numéro d'ordre de chaque élément.
- Le tableau de bord signale les **brouillons** et les **traductions
  anglaises manquantes** (marquées « à relire »).

---

## 5. Réglages du site (administrateur uniquement)

Menu **Réglages** :

- **Numéro WhatsApp** ⚠ À vérifier en priorité : c'est le numéro qui
  reçoit les demandes de réservation et de contact générées par le site.
- **Mode démo** : désactivez la mention « contenu de démonstration »
  affichée sur le site public une fois les vraies informations en place.
- Coordonnées de l'hôtel, adresses e-mail, horaires, politiques de
  réservation, bannières des pages.

---

## 6. Personnel (administrateur uniquement)

Menu **Personnel** :

- **Inviter** : saisissez l'e-mail de la personne et choisissez un rôle.
  Elle reçoit un e-mail d'invitation pour choisir son mot de passe.
- **Rôles** :
  - **Éditeur** — peut modifier tout le contenu du site ;
  - **Administrateur** — peut en plus gérer le personnel, les réglages
    et les données personnelles.
- **Retirer l'accès** d'un membre parti de l'équipe.
- Le dernier administrateur ne peut être ni retiré ni rétrogradé
  (protection du système).

---

## 7. Suivi des demandes (administrateur uniquement)

Les menus **Réservations**, **Messages** et **Prospects** afficheront les
demandes envoyées via le site. À ce jour, les clients vous contactent
directement **via WhatsApp** : ces écrans resteront vides tant que la
capture en ligne n'est pas activée (évolution prévue).

---

## 8. En cas de problème

| Symptôme | Que faire |
|---|---|
| « Traduction manquante » sur un contenu | Complétez le champ anglais (EN) de ce contenu |
| Lien d'e-mail expiré | Redemandez-en un depuis « Mot de passe oublié » ou demandez une nouvelle invitation |
| Un changement n'apparaît pas sur le site | Attendez 1 heure, ou vérifiez dans une fenêtre de navigation privée ; vérifiez que le contenu est bien « Publié » |
| Plus accès à votre téléphone (2FA) | Utilisez un code de secours noté à l'activation |
| Autre chose | Contactez la personne qui gère le site |

---

## 9. Bonnes pratiques

- Ne partagez jamais votre mot de passe ; invitez plutôt un collaborateur
  depuis le menu **Personnel**.
- Déconnectez-vous (`Mon compte` → Déconnexion) sur un ordinateur partagé.
- Gardez une **copie des textes importants** (tarifs, politiques) avant
  une grosse modification : le journal d'audit conserve l'historique mais
  pas les anciennes valeurs.
